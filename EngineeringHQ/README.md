# Engineering HQ

A macOS app that collects engineering tooling and status in one place. It
has a main window with a sidebar of modules, and a menu bar icon with quick
actions from every module.

## Modules

- **Containers**: lists Apple `container` CLI containers and machines.
  Start or stop a container, open a Terminal shell in a machine, and start
  or stop container services. Updates live when containers change from
  elsewhere.
- **Monitor**: runs read-only checks against the public ChetBackend
  endpoints in Local, Development and Production. Each call shows its HTTP
  status, time, and any validation error, plus a snippet of the body.
  Press **⌘R** or double-click an environment to run it.

The menu bar icon turns green when a container is running and red when a
module reports a failure.

## Requirements

- macOS 13 or later.
- For Containers: Apple's [`container`](https://github.com/apple/container)
  CLI at `/usr/local/bin/container` or `/opt/homebrew/bin/container`.

## Build

The Xcode project is generated by
[XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`:

```bash
cd EngineeringHQ
xcodegen generate
xcodebuild -project EngineeringHQ.xcodeproj -scheme EngineeringHQ \
  -configuration Release -destination 'platform=macOS' build
```

See [AGENTS.md](AGENTS.md) for the module architecture, how to add a
module, and install steps.
