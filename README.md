# ContainerTray

A macOS menu bar app for Apple's `container` CLI.

ContainerTray shows your containers and container machines in a menu.
Click a container to start or stop it. Click a machine to open an
interactive shell in it.

## Features

- Lists containers and shows their run state (green = running).
- Click a container to toggle it: start it if stopped, stop it if running.
- Lists container machines and shows their run state.
- Click a machine to open Terminal and run `container machine run` in it.
  There is no stop action for machines — exit the Terminal session to
  stop it.
- The menu bar icon turns green when any container is running.

## Requirements

- macOS 13 or later.
- Apple's [`container`](https://github.com/apple/container) CLI, installed
  at `/usr/local/bin/container` or `/opt/homebrew/bin/container`.

## Build

This is an Xcode project. The `.xcodeproj` file is generated by
[XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`. To
change project settings, edit `project.yml`, then run:

```bash
xcodegen generate
```

To build:

```bash
xcodebuild -project ContainerTray.xcodeproj -scheme ContainerTray \
  -configuration Release -destination 'platform=macOS' build
```

See [AGENTS.md](AGENTS.md) for more build details, including how to build
without a paired Apple Developer team.

## Install

Copy the built `ContainerTray.app` to `/Applications` and open it. To run
it at login, add it in System Settings → General → Login Items &
Extensions.
