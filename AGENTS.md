# ContainerTray

A macOS menu bar app for Apple's `container` CLI. It shows containers in a
menu and lets you start or stop them with a click.

## Project type

This is a real Xcode project, not a Swift Package. The `.xcodeproj` file is
generated by `xcodegen` from `project.yml`. Do not hand-edit
`ContainerTray.xcodeproj`. To change project settings (bundle ID, deployment
target, Info.plist keys, build settings), edit `project.yml`, then run:

```bash
xcodegen generate
```

## Source layout

- `ContainerTray/Sources/ContainerTrayApp.swift` — app entry point.
  `MenuBarExtra` scene and the menu bar icon (SF Symbol `cylinder` /
  `cylinder.fill`, green when a container is running).
- `ContainerTray/Sources/ContainerManager.swift` — `ObservableObject` that
  holds the container list and drives refresh/toggle actions.
- `ContainerTray/Sources/ContainerCLI.swift` — thin wrapper that shells out
  to the `container` binary (`list`, `start`, `stop`).
- `ContainerTray/Sources/ContainerModel.swift` — `ContainerItem` and the
  `Decodable` types that match `container list --format json` output.
- `ContainerTray/Sources/ContainerMenuView.swift` — the menu content shown
  when the tray icon is clicked.

## Key facts

- The app is `LSUIElement` (no Dock icon, no main window). It lives only in
  the menu bar.
- `MenuBarExtra` renders SF Symbol labels as a monochrome template image,
  ignoring `.foregroundColor`/`.renderingMode`. To show a colored icon, build
  an `NSImage` with a `SymbolConfiguration(paletteColors:)`, set
  `isTemplate = false`, then wrap it with `Image(nsImage:)`. See
  `menuBarIcon` in `ContainerTrayApp.swift`.
- `container` CLI is expected at `/usr/local/bin/container` or
  `/opt/homebrew/bin/container`.

## Build

The build machine may not have `xcode-select` pointed at a full Xcode
install. Set `DEVELOPER_DIR` explicitly and build with ad-hoc signing:

```bash
export DEVELOPER_DIR=/Applications/Xcode-27.0.0-Beta.5.app/Contents/Developer
xcodebuild -project ContainerTray.xcodeproj -scheme ContainerTray \
  -configuration Debug -destination 'platform=macOS' build \
  CODE_SIGNING_ALLOWED=NO
```

Use `-configuration Release` for the build to install into `/Applications`.

## Installing / running

To install and run the built app:

```bash
pkill -x ContainerTray 2>/dev/null
rm -rf /Applications/ContainerTray.app
cp -R "$(xcodebuild -project ContainerTray.xcodeproj -scheme ContainerTray \
  -configuration Release -showBuildSettings 2>/dev/null \
  | awk -F' = ' '/ BUILT_PRODUCTS_DIR /{print $2}')/ContainerTray.app" /Applications/
open /Applications/ContainerTray.app
```

Default to a Debug build-only verification (no install/relaunch) unless the
user asks to install or run the app.
